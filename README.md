# Phuong Jewelry

Website rebuild for the family-owned jewelry shop at 808 Franklin Street, Oakland, California.

## Direction

Real business photography, attributed customer excerpts, a restrained editorial design, and direct inquiries. No illustrated product placeholders, fabricated reviews, invented stock, or simulated checkout.

The initial implementation is being added in a follow-up commit. Public-source research and unresolved photo/review access limitations will be documented in `docs/SOURCES.md`.
